# Cardinar

Сайт: https://cardinarpidors.github.io/cardinar/

## Автономное демо

Сервер и база данных не нужны. Вход: `director` / `demo`.

Другие логины (пароль `demo`): `admin`, `finance`, `chief`, `priyom`, `lamsklad`, `lamhead`, `lamoper`, `laser`, `vyshivka`, `shveya`.

Тестовые данные и изменения сохраняются в localStorage этого браузера. Они не синхронизируются между устройствами. Очистка данных сайта удаляет изменения. Это демонстрация, а не защищённая система: не вводите реальные пароли, персональные и производственные данные. Обмен с 1С не выполняется.

Запуск локально: `python3 -m http.server 8000` из корня репозитория, затем открыть http://localhost:8000/.

Серверный исходный код сохранён в `cardinar-backend`. Для возврата к серверной версии удалите подключение `offline.js` в `production-accounting-1c-demo/index.html` и настройте API.
